# lovelife

口播文稿写作方法研究与可复用 Skill。

## 内容

- `analysis/拆解报告.md` — 对一篇 7,797 字 / 32 分钟修行主题口播稿的详细写作方法拆解（量化画像、结构时间轴、12 项核心手法、写作配方）
- `analysis/source-transcript.txt` — 被拆解的原文稿（带时间戳）

- `blogs/因果千万别只照别人.md` — 原创文章《因果千万别只照别人》博客对话版（若静问，师傅答，约 7,200 字）
- `scripts/因果千万别只照别人.md` — 同题 30 分钟口播稿（v2 · 换骨版，带分钟级时间戳，QA 全过）

- `skills/koubo-script-writing/` — 倒推出的写作 Skill（可直接作为 Agent Skill 使用）
  - `SKILL.md` — 主文件：三条铁律 + 8 步写作流程 + 10 条核心手法速查
  - `references/structure-template.md` — 30 分钟时间轴骨架模板与字数配额
  - `references/patterns.md` — 句式模式库（重定义、金句四式、钩子、转场、口语体规则）
  - `references/story-bank.md` — 故事素材卡 + 故事三步法 + 可扩展素材池
  - `references/checklist.md` — 交稿前自检清单
