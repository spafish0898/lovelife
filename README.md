# lovelife · 十点君暖文写作 Skill

把「十点君」式情感暖文的风格沉淀为一个可复用的写作 Skill：学会它，任何主题都能写出原文《选择性入局》那样——开场共鸣、故事递进、金句频出、最后给方法的公众号推文。

## Skill 文件

```text
lovelife/
├── SKILL.md                          # 主技能：风格DNA + 七段式结构 + 写作流程 + 自检清单
├── references/
│   ├── structure-template.md         # 每段功能/句式/原文示例/套用模板 + 过渡句库
│   ├── case-library-method.md        # 个人/名人/文学三层论据选法 + 备用案例池 + 权威背书库
│   └── golden-sentences.md           # 五大金句公式 + 埋点位置图 + 改写示例
└── examples/
    └── full-breakdown.md             # 蓝本原文逐段拆解标注 + 写作指纹统计
```

## 快速使用

1. 让 AI 阅读 `SKILL.md`（Claude / 支持 Agent Skills 的平台会自动加载）。
2. 给主题即可，例如：
   - "用这个 skill 写一篇《成年人最大的清醒：有限度善良》，2000字"
   - "把'我帮亲戚担保贷款被坑'的经历改写成十点风"
3. AI 会按七段式输出正文，并附金句清单和自检表。

## 风格一句话

> 痛点共鸣开场 → 新概念破局 → 三层故事递进（个人→名人→文学，代价越来越重）→ 心理学背书 → 三步方法论收束，全程第二人称陪伴口吻。
