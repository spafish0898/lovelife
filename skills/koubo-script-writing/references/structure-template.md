# 结构模板：30 分钟口播稿时间轴骨架

按 240 字/分钟配速。总长 7,500–8,000 字。方括号 `[...]` 为填空位；每格标注功能与配额。
完成后把时间戳按每 ≈240 字切一个写回稿面（便于剪辑与节奏自查）。

---

## 完整时间轴

### [00:00–01:00] 开场钩子（≈240 字）
**功能：3 秒给结论，30 秒戳痛，60 秒给出口。**
```
[年龄/人群限定]以后，一定要通过[修行/方法]，好好[单字心法]自己[一遍/回来]。
[人群]到了[年龄]，慢慢会发现一件事：我们这一辈子，好像都在[四连排比：养孩子、养房子、养车子、养面子]。
忙忙碌碌几十年，什么都顾到了，可回过头来才发现——唯独自己，[被养得最潦草/被过得最潦草]。
[三个身体/心理信号]。以前觉得还有很多时间，可真正走到人生中段：
你开始看见[父母老去]，看见[身体恢复变慢]，也开始经历[身边人的离开]。
这个时候你才会真正明白：[死亡/无常]，从来没有我们想象中那么遥远。
```
**要求**：四连排比 → "唯独自己"反差 → 危机必须在本段末尾或下一段开头立刻给出口（故事）。

### [01:00–02:00] 故事一：立信（≈240 字）
**功能：用经教故事代替说教，结尾把故事转向观众。**
- 引用精确到出处（"《XX经》卷十九"）
- 问答体推进，一句一画面（三个排比问句）
- 收尾必须是元问题：`既然这些你都已经看见了，有没有因此警醒自己？`

### [02:00–03:00] 重新定义核心概念（≈240 字）
**功能：消除门槛，一句话讲清"这到底是什么"。**
- 设问自答：`有人问我，X到底是什么？是A、B、C吗？这些当然是，但真正重要的不只是外在形式。`
- 一句话定义：`用最简单的话讲，所谓X，就是[动词链]。`

### [03:00–04:00] 提出"一个字"文眼 + 破误解（≈240 字）
**功能：全片文眼落地。**
- `如果一定要用一个字来概括，我更愿意把它理解成——[字]。`
- 先破：`我这里讲[新概念]，不是[庸俗理解]，那个不叫X，那更像是[贬义定性]。`
- 再立：`真正的X，[正面定义]。`
- 抛出隐患钩子：`但这里还有个很重要的问题——不是只要开始修，就一定修得对……`

### [04:00–05:15] 预告与承诺（≈300 字）
**功能：给观众"听完的理由"。**
- 价值承诺：`这四样东西，越早开始X，后半生就越安稳；可如果一直不X，年龄越往后走，很多苦只会越来越明显。`
- 方法预告：`今天这场分享，我会结合[故事类型]和[案例类型]，讲一讲为什么，也讲一讲回到现实以后怎么修。`
- 降门槛：`内容可能有一点深，但我会尽量讲得简单一点，各位不用着急，慢慢听。`

### [05:15–06:00] 中段互动 CTA（≈150 字）
**功能：第一板块前的留言引导。**
- 给一句可复制的祝福语：`在留言区留下一句：[8–12字祝福]。这句话是祝福别人，也是提醒自己。`
- 立即转场开讲：`那接下来，我们就正式来说一说，[主题]到底是哪几样东西。`

### [06:00–09:30] 板块一（≈850 字）
### [09:30–13:00] 板块二（≈850 字）
### [13:00–17:30] 板块三（≈1050 字，含 4 个子概念）
### [17:30–22:00] 板块四（≈1050 字，含 3 个角度）
**每个板块固定四拍：**

```
拍1 故事引入（250–350字）
    [我给你讲一个XX里有名的故事] + 对话体复述 + 画面细节 + 反差冲突
拍2 义理解读（200–300字）
    元问题转向观众（"各位听懂了其中的禅意吗？"）
    + 逐句白话翻译 + 至少 1 处"不是X，是Y"重定义
拍3 生活对照（200–300字）
    "我给你举个例子：你正在[开车/吵架/加班]……"
    + 比喻（河与水滴 / 壳 / 车停不下来）
拍4 金句收束（50–100字）
    对仗或反常理短句定住本板块（"你把身体当工具，身体就用病痛来提醒你"）
```

**板块固定转场句（替换主语即可）：**
- `[上一块]安顿好了，接下来要养的，就是[下一块]。`
- `这最后一个要养的啊，就是[X]。`
- 板块四收尾转总结：`到这里，几样东西就讲完了：[A]是基础，[B]是关键，[C]是深化，[D]是根本。几样东西不是几个独立的任务，是一张互相滋养的网。`

### [22:00–25:00] 总结 + 三个角度收拢（≈700 字）
- 每个角度配一组"看见X，你就会……但不再……"的生活对照
- 收束句：`这就是[X]开始生起来的时候。`

### [25:00–28:15] 五个落地场景（≈750 字）
固定句式，每场景 ≈150 字：
```
第N个场景：[场景名：早晨醒来/遇到不顺心/和人争论/面对失去/睡前]
[不要做什么] → [先做什么] → [带数字的最小指令：停三秒/吸4呼6/五分钟]
[预期效果一句话] + [心法金句]（"你理它，它就用舒服来回报你"）
```

### [28:15–31:30] 五个误区排雷（≈750 字）
固定句式，每误区 ≈140 字：
```
第N个误区：[误区名]
自降姿态开场（"这些坑很多人都踩过，包括我自己"）
[现象描述，用排比列 2–3 个] → [定性一句话：这还是贪/这是自欺]
[化解：一句反常识短句]（"修行不是追求什么，是放下什么"/"慢慢来，比较快"）
```

### [31:30–结尾] 温情收尾 + 分层 CTA（≈600 字）
顺序不可乱：
```
1. 祖师引语（文言原文 + 立即白话翻译）
2. 加减法对比："前半生都在做加法，[四连排比]。加到最后，你拥有的越来越多，但你自己越来越小。"
3. 排比找回自己："那个[会因为一朵花停下来的]自己，那个[受了委屈会哭的]自己，那个[对世界还抱有好奇]的自己——他没有死，他只是被你埋在了一堆应该和必须下面。"
4. 不需回答的提问："如果今天晚上你要和自己说一句话，你会说什么？[四个选项排比]……这个问题不需要你回答，你在心里想一想就好。"
5. 身体性动作："说完以后，给自己一个拥抱。真的，抱一下自己。"
6. 四层 CTA：
   ① 点赞热推（"如果你觉得这些话对你有一点触动"）
   ② 留言选择题（"你觉得自己最该先减哪一样：A、B、C，还是D？"）
   ③ 随喜/关注（价值包装："一念善心，一份善行"）
   ④ 祝福回环 + 下集预告（"愿我们都能……下一支影片相见"）
```

## 结构自查（写完骨架先过这 6 问）

1. 四个板块是否**同构**（都是四拍）？不同构观众会累。
2. 每个板块是否有独立的**金句收束**？
3. 转场句是否齐全（上一块→下一块的固定句式）？
4. 故事是否覆盖了全片 40% 以上篇幅（30 分钟稿至少 4 个大故事）？
5. 落地场景与误区是否都是 **5 个**（奇数列表比偶数稳）？
6. 结尾是否回扣了标题里的关键词？
