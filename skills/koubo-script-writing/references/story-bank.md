# 故事素材库 + 故事三步法

口播稿的骨肉是故事：30 分钟稿至少 4 个大故事（每个 250–400 字），外加 2–4 个小例证。
本库分两部分：① 范文四张故事卡（含结构坐标，可直接替换主题复用）；② 可扩展素材池。

---

## 一、故事三步法（所有故事统一处理）

```
第1步 戏剧化复述
   - 对话体推进（谁问谁答），一句一画面
   - 必须有视觉细节：雪没过膝盖 / 砍断左臂 / 挑着一担书 / 一口气吹灭蜡烛
   - 必须有反差或冲突：学霸被卖饼婆婆问住；皇帝式的排场被一句话击穿
第2步 白话翻译
   - 古文原句出现后 3 句内给白话，一句对一句
第3步 转向观众
   - 元问题："这个故事真正重要的地方，不只是X，而是问你……"
   - 或直接挂钩板块主题："为什么慧可说找不到心，达摩就说心已安好了？因为……"
```

## 二、范文四张故事卡（附结构坐标，可仿写）

### 卡1 · 三使者（板块：开场立信 / 坐标 01:00）
- **出处背书**：《长阿含经》卷十九（精确到卷，增强可信度）
- **剧情**：命终之人见阎罗王 → 阎罗连问三句（白发苍苍弯腰驼背的老人 / 卧床不起的病人 / 被人送葬的死者）→ "这就是老、病、死三位使者"
- **转折句**：`这个故事真正重要的地方，不只是告诉你人会老会病会死，而是问你——既然都看见了，有没有因此警醒自己？`
- **可替换场景**：任何"你早就见过警告信号"的主题（健康、关系、财务）

### 卡2 · 慧可断臂求法（板块：养心 / 坐标 09:30）
- **剧情**：达摩面壁九年 → 神光雪中立 → 断臂 → 拜师 → "我心未宁，乞师与安" → "将心来，与汝安" → "觅心了不可得" → "我与汝安心竟"
- **白话句句对应**（范文原样处理，是三步法的范本）
- **生活对照**：开车被别车 → 愤怒是现象不是你 → 河与水滴的比喻
- **收口金句**：`念起即觉，觉之即无。`
- **可替换场景**：任何"你以为的那个东西其实抓不住"的主题（焦虑、自我认同、情绪管理）

### 卡3 · 布袋和尚《插秧歌》（板块：养性 / 坐标 13:40）
- **偈子**：手把青秧插满田，低头便见水中天；六根清净方为道，退步原来是向前。
- **人物小传**：背布袋、放袋叉手、背袋就走——"放下就是佛，提起就是道"（用动作说法的疯和尚人设）
- **双重解读**：低头=道在脚下；退步=前进（插一行退一步，往前走反而踩坏秧苗）
- **可替换场景**：任何"反向操作才对"的主题（慢下来、示弱、放手）

### 卡4 · 德山烧经（板块：养慧 / 坐标 17:30，全片最长故事≈600字）
- **人设反差**：学霸、精研《金刚经》、写《青龙疏钞》、自负南下挑战禅宗
- **三连打击**：卖饼婆婆"三心不可得，你点的是哪个心？"→ 答不上来不卖饼 → 龙潭吹烛大悟
- **高潮动作**：烧掉一辈子的注解
- **名言**：`穷诸玄辩，若一毫置于太虚；竭世枢机，似一滴投于巨壑。`（+立即白话）
- **收口**：`慧不是知识……直到蜡烛被吹灭的那一刻，他用整个生命看见了。`
- **可替换场景**：任何"知识不等于智慧"的主题；也可拆出"吹烛"单用

## 三、可扩展素材池（按主题取用，使用前按三步法加工）

| 素材 | 类型 | 适用板块 | 一句话钩子 |
|---|---|---|---|
| 佛陀教入出息念（杂阿含经） | 经教方法 | 养身/入门 | "三口气不到，脑子就开始跑了" |
| 憨山大师"向外驰求/迷头认影" | 祖师引语 | 收尾升华 | 文言+白话，压轴用 |
| 野狐禅（不落因果） | 公案 | 养慧/语言的坑 | 一句话改变身份 |
| 赵州"吃茶去" | 公案 | 养心/平常心 | 无论贵贱都是吃茶去 |
| 二祖安心、三祖僧璨"将心来" | 公案串 | 养心 | 可与卡2连用 |
| 庞居士"好无事" | 公案 | 养性/知足 | 最好的是"没事" |
| 无门关"春来草自青" | 公案 | 养慧/无常 | 不用管，时候到了自然发生 |
| 临终四问（地位/财富/妻儿/身体） | 民间故事 | 开场立信 | 与三使者同构，可换用 |
| 雁衔枯草 / 三世因果 | 经教故事 | 缘起 | 具象化"因缘" |
| 船子德诚"覆舟" | 公案 | 收尾 | 传法即散场，制造余韵 |

> 选材原则：一个板块只用一个大故事；故事之间类型错开（经教问答 / 禅宗公案 / 偈颂解读 / 祖师语录），避免连续两个同构故事让观众腻。

## 四、自建故事的检查点

- [ ] 有没有**至少一问一答**的对话（独白不算故事）
- [ ] 有没有**一个画面细节**能让人闭眼看见（雪、血、烛、布袋）
- [ ] 有没有**反差**（身份反差/结果反差/预期违背）
- [ ] 文言是否≤3句且句句有白话
- [ ] 结尾是否把皮球踢回观众（元问题/挂钩板块主题）
- [ ] 300–400 字内讲完（讲不完就砍，口播故事不是论文注脚）
