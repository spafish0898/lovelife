# 交稿自检清单

全部通过再交稿。`★` 为一票否决项。

## A. 定位与结构
- [ ] ★ 标题 = 人群限定 + "一定要" + 单字/动词心法，且首段 60 秒内出现
- [ ] ★ 全片只有一个文眼，被回扣 ≥6 次
- [ ] ★ 四个板块同构（都是"故事→解读→对照→金句"四拍），各有独立金句
- [ ] 板块转场句齐全（上一块→下一块，用固定句式）
- [ ] 焦虑点（老病死/失去/疲惫）全部在本篇内被回收，无裸露焦虑
- [ ] 骨架齐全：钩子→故事立信→定义→文眼→预告→中段CTA→四板块→总结→5场景→5误区→收尾CTA

## B. 节奏与留存
- [ ] ★ 随机抽 3 个"240 字窗口"朗读，每个窗口至少含：1 个新信息/1 个钩子/1 个"你"
- [ ] 每 60–90 秒有一次信息块切换（新故事/重定义/指令/设问，至少占一样）
- [ ] 序号导航连续无断（第一个…第N个，观众随时知道自己在哪）
- [ ] 故事总篇幅 ≥ 全片 35%
- [ ] 每个故事结尾有元问题把观众拉回自己

## C. 语言（朗读测试）
- [ ] ★ 全篇 0 个"但是/可是"（用"但""可"单字）
- [ ] ★ 0 个书面关联词（因此/然而/与此同时/综上所述）
- [ ] ★ 所有文言/经句在 3 句内有白话翻译
- [ ] "你"密度：平均每 30–40 字 1 次；连续无"你"段落 ≤80 字
- [ ] 单句 ≤25 字；无超过 40 字的长句
- [ ] "不是X，是Y"重定义每 2–3 分钟 ≥1 处，单板块 ≤3 处
- [ ] 语助词（啊/哦/真的/说到底）每 5 分钟 2–3 处（有温度但不油腻）
- [ ] 每个抽象道理交齐三样税：故事或比喻 + 重定义 + 生活场景对照

## D. 落地与互动
- [ ] ★ 5 个落地场景，每个含"禁止动作→带数字的替代动作→预期效果→心法句"
- [ ] 5 个误区，开篇有自降姿态（"包括我自己"），每个埋 1 可传播短句
- [ ] CTA 四层齐全且顺序正确：中段祝福语留言 → 点赞热推 → 留言选择题 → 随喜/下集预告
- [ ] 留言问题是**选择题**（A/B/C/D 式），不是开放题
- [ ] 结尾祝福语回扣标题关键词（首尾词汇回环）

## E. 素材真实性与合规
- [ ] 经名/人名/偈语有出处，拿不准的不写"卷X页X"式伪精确
- [ ] 公案情节不张冠李戴（达摩慧可、德山、布袋等主干情节需核对）
- [ ] 不制造恐慌、不承诺疗效、不贬低具体人群/信仰
- [ ] 涉及健康的内容以"觉察/规律生活"为限，不替代医疗建议

## F. 字数与配速
- [ ] 总字数 7,500–8,000（30 分钟）；按 240 字/分钟换算误差 ≤2 分钟
- [ ] 各段配额与 `structure-template.md` 的表格偏差 ≤15%
- [ ] 时间戳按每 ≈240 字切分回写，供剪辑对轨
