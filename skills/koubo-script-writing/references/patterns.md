# 句式模式库（从范文倒推，可直接套用）

所有例句均出自范文原文。使用方式：写到对应位置时挑一条换词套用，不要原句照抄超过 8 个字。

---

## 1. 重定义句式 "不是 X，是 Y"（全片 25 处，最高频论证武器）

**功能**：破误解（显示你懂行）+ 立反常识新解（给观众获得感）。

| 子型 | 句式 | 范文例 |
|---|---|---|
| 破庸俗化 | X 不是 [庸俗理解]，那个不叫 X，那更像是 [贬义定性] | "重养自己不是养生享受……那更像是一种补偿" |
| 破名词误解 | X 不是 [常见误读]，是 [本质] | "忍辱不是忍气吞声"；"柔软不是软弱"；"知足也不是穷开心" |
| 破行为误解 | X 不是 [错误做法]，是 [正确做法] | "修行不是追求什么，是放下什么"；"退步不是消极，不是什么都不干" |
| 破情绪误解 | 不是 [情绪A]，恰恰因为 [事实]，所以 [情绪B] | "不是不珍惜，恰恰因为知道它会变，所以更懂得珍惜" |
| 定性打击 | 这 [不是/还是] X，这是 Y | "这是自欺，不是修行"；"那不是自信，那是我慢" |
| 石头式反讽 | 那是 X，不是 Y | "心如止水？那是石头，不是人" |

**配额**：每 2–3 分钟至少 1 处；一个板块内不超过 3 处（多了变抬杠）。

## 2. 金句四式（每板块收尾必用其一）

### 式 A：对仗转折（赢/输、好/坏互换）
- "你赢了一场争论，输了一个朋友；你赢了一笔生意，多了一个敌人。"
- "你对身体好，身体就对你好；你把身体当工具，身体就用病痛来提醒你。"
- 模板：`你[得到A]，就[失去B]；你[对待X如何]，X就[如何回报你]。`

### 式 B：三连/四连排比（动词+名词，同构）
- "养孩子、养房子、养车子、养面子。"
- "减欲望、减执念、减恐惧、减我慢。"
- "加知识、加财富、加地位、加关系。"
- 模板：`[动词]+[抽象名词] ×4`，前两个具体、后两个抽象，第四个点题。

### 式 C：反常理短句（8 字内，可传播）
- "退步原来是向前。"
- "慢慢来，比较快。"
- "放下就是佛，提起就是道。"
- 模板：把常识词序颠倒或悖论化，中间用"原来/才是/其实就是"连接。

### 式 D：比喻收束（把整段道理压成一个意象）
- 心念：河与水滴（"你看到河水在流，但找不到一个固定的河"）
- 自我防护：壳（"壳越穿越厚，到最后你自己都脱不下来了"）
- 四板块关系：一张互相滋养的网
- 找回自己：挖出来、擦干净、好好养着
- 模板：`本段道理 → 一个日常可见的物象 → 物象的动态变化 → 一句定性`

## 3. 钩子句式（每 60–90 秒用一次，防止划走）

| 类型 | 句式 | 例句 |
|---|---|---|
| 悬念承接 | 也正因为这样…… | 段尾吊住，下段开头接故事 |
| 元问题 | 这个故事真正重要的地方，不只是[表层意思]，而是问你…… | 三使者故事后 |
| 追问观众 | 各位听懂了其中的禅意吗？ | 公案翻译完 |
| 模拟反驳 | 你可能会说，这有什么难的？你试试看…… | 引出体验指令 |
| 抛隐患 | 但这里还有个很重要的问题——不是只要开始修，就一定修得对。 | 文眼提出后 |
| 反常断言 | 修行最怕的不是慢，而是方向错了。 | 制造认知缺口 |
| 升格声明 | 这段对话，是整个禅宗最核心的对话之一。 | 故事前抬高期待 |
| 互动命令 | 各位不用着急，慢慢听。 | 长段落前安抚 |

## 4. 转场句式（板块之间，换主语即可复用）

- `身体安顿好了，接下来要养的，就是心。`
- `接下来要养的，就是性。`
- `这最后一个要养的啊，就是慧。`
- `到这里，四样东西就讲完了：A 是基础，B 是关键，C 是深化，D 是根本。`
- `道理讲完了，下面讲现实生活中具体落地的方法。`
- `讲完了这几个场景，我再跟你讲几个常见的误区——这些坑，很多人都踩过，包括我自己。`

## 5. 三步翻译古文/公案（照抄这个处理顺序）

```
① 对话原文（制造机锋感）："将心来，与汝安。"
② 立即白话（不许观众卡壳）："你把心拿来，我帮你安。"
③ 逐个动作心理化（把古人写成观众）："慧可愣住了——他去找自己的心，
   那个让他不安的东西，到底在哪里？在胸口吗？在脑子里吗？"
④ 收口定性："为什么慧可说找不到心，达摩就说心已经安好了？因为……"
```
规则：**任何文言出现后 3 句内必须有白话翻译**；故事讲完必须接一个把皮球踢回观众的问题。

## 6. 场景落地句式（数字给抓手）

- `在你要发火、要抱怨、要反击之前，先停三秒，在心里轻轻说一句：哦，这个情绪来了。`
- `你可能觉得三秒钟太短了，能有什么用？但长久练习下来你会发现，火已经消了一半——因为你从成为愤怒，变成了观察愤怒。`
- `问自己一个问题：就算我赢了这场争论，我能得到什么？`
- 模板：`[触发情境] → [禁止动作] → [带数字的替代动作] → [预期效果] → [心法短句]`

## 7. 收尾专属句式

- 加减法：`人这一辈子，前半生都在做加法……加到最后，你拥有的越来越多，但你自己越来越小。`
- 找回排比：`那个[细节1]的自己，那个[细节2]的自己，那个[细节3]的自己——他没有死，他只是被你埋在了一堆应该和必须下面。`
- 需回答又不需回答的提问：`这个问题不需要你回答，你在心里想一想就好。如果今天晚上你要和自己说一句话，你会说什么？`
- 身体动作：`说完以后，能给自己一个拥抱。真的，抱一下自己。`
- 留言选择题：`你在留言区聊聊：你觉得自己最该先[减/养/改]哪一样？是 A、B、C，还是 D？你的一句话，也许能点醒另一个正在看留言的人。`
- 祝福回环：`愿我们都能在人生的下半场，[回扣标题关键词]。`

## 8. 口语体硬规则（语言层）

1. **零"但是/可是"**：用"但""可"单字替代（范文全篇 0 处）。
2. **短句**：单句 ≤ 25 字；一个句子只装一个意思。
3. **语助词降姿态**：说到底啊 / 啊 / 哦 / 真的 / 多唠叨几句——每 5 分钟 2–3 处。
4. **禁止书面关联词**：因此/然而/与此同时/综上所述 → 换成"所以""可""这时候""说白了"。
5. **设问开路**：每引入一个新概念先问一句（"呼吸为什么这么重要？"）。
6. **指令用现在时**："你闭上眼睛，试着观察自己的呼吸"——让观看变成参与。
