# 三类论据选取方法与备用案例池

> 十点文的核心说服力来自"三层论据，代价递进"。本篇教你每层选什么、去哪找、怎么写。

## 1. 选案总原则：代价递进线

```text
个人小事（失去：牵挂/心神） → 名人轶事（失去：钱 + 朋友） → 文学影视（失去：一生/自由）
         无形代价                     有形+关系代价                    极端代价
```

三层必须满足：**越往后，失去的东西越贵、越不可逆**。如果第三层不够重，宁可换案例，不可降调门。

## 2. 第一层：个人亲历小事

**选题公式**：`低权力身份 + 高频小善 + 对方突然消失/变故 + 我久久不能释怀`

| 身份 | 小善 | 变故 | 适用主题 |
|---|---|---|---|
| 代课老师 | 每天讲阅读题 | 女孩休学消失 | 入局、边界 |
| 合租室友 | 每晚等门、带饭 | 对方突然搬走 | 习惯、依赖 |
| 新人员工 | 帮同事带咖啡、改PPT | 对方升职后疏远 | 职场付出 |
| 异地子女 | 每晚给父母打视频 | 父母报喜不报忧生病 | 亲情亏欠 |

**写法三要素**：

1. 他人劝 + 我不听（"有同事告诉我……我总是笑笑不说话"）——为后悔铺垫；
2. 时间颗粒（每天/有一天/一周两周/第二学期）——营造纪实感；
3. 感悟反转（"现在回想起来，当初觉得……是不对的"）——点题。

**虚构伦理**：允许基于用户素材合理虚构细节，但不得编造可查证的公共事实；第一人称故事默认视为"作者讲述"，不宣称新闻真实。

## 3. 第二层：名人轶事 / 社会新闻

**选人标准**：

- 草根出身、读者有同情心（宝石老舅、大衣哥、李雪琴、张桂梅）；
- 事件含"钱/情/义"三元素，结局最好是"钱没了、朋友也没了"式双输；
- 有公开访谈/综艺原话可引用，增加真实感。

**备用案例池**（可直接取用，写作时需核实表述为"据公开报道/访谈"）：

1. **宝石老舅借份子钱**（原文用例）：结婚份子钱借兄弟 → 自己紧巴 → 讨要失联 → "差点儿跪在成都马路上" → 绝交。适用：借钱、义气、边界。
2. **东野圭吾式反例亦可作此层**：若第三层另选，此层可用"李雪琴为朋友担保"类都市传说——注意必须模糊化处理（"有位脱口秀演员曾讲过……"），避免造谣。
3. **社会新闻型**：为亲戚担保贷款、帮朋友带货垫钱、深夜长途共情闺蜜致抑郁——选近1年热搜，写"前段时间热搜上……"开头。

**叙事链条（6节）**：不忍 → 牺牲细节（具体钱物）→ 连带效应123 → 想讨不敢 → 鼓勇行动 → 暴击结局 + 网友反应。

## 4. 第三层：文学 / 影视 / 历史

**选题公式**：`大众知名 + 主角为他人入局 + 代价极端（坐牢/死/一生尽毁）+ 有专业解读空间`

| 作品 | 入局动机 | 极端代价 | 点评角度 |
|---|---|---|---|
| 《嫌疑人X的献身》石神 | 为所爱靖子脱罪 | 天才→杀人犯，余生坐牢 | 献身精神背后的代价 |
| 《活着》徐福贵 | 为家人忍让赌局 | 亲人相继离世 | 命运入局的无奈 |
| 《漫长的季节》王响 | 为儿子追凶 | 余生困在火车上 | 执念即深局 |
| 《红楼梦》贾母/王熙凤 | 为家族操持 | 机关算尽、晚景凄凉 | 越操心越入局 |
| 诸葛亮 | 为蜀汉鞠躬尽瘁 | 星落五丈原 | 无私型给予者的极致 |

**复述纪律**：情节 ≤150字，永远用"很多人感动于……可却忽略了他所付出的代价"转折到代价清单，最后必须落到「轻/中/重」分级句。

## 5. 权威背书库（方法论段用）

每条建议配一个，轮换使用避免重复：

- **阿德勒「课题分离」**：《被讨厌的勇气》——一切烦恼来自干涉他人课题。适用：边界、拒绝、亲子。
- **亚当·格兰特《给予者》**：无私型给予者垫底，自我保护型给予者最成功。适用：付出、助人、职场。
- **卡普曼戏剧三角**：拯救者→受害者→迫害者轮转，好心拯救终成加害。适用：闺蜜劝架、借钱、原生家庭。
- **沉没成本 / 止损点**：行为经济学——已付出的不是继续的理由。适用：及时抽身、离婚、辞职。
- **非暴力沟通四步**：观察—感受—需要—请求，给出拒绝话术模板。适用：第三条建议的"怎么说"。
- **荣格「面具与阴影」**：老好人是面具，压抑的愤怒是阴影。适用：讨好型人格主题。

引用格式：`心理学家XX提出…… / XX教授在《XX》一书中，将……分为两种：……`， Mall:概念后必须紧跟一句人话解释，不拽术语。
