# 七段式结构模板与过渡句库

> 对应 SKILL.md 第3节。本文档给出每一段的「功能 → 句式 → 原文示例 → 可套用模板」。

---

## ① 灵魂三问开场（~300字）

**功能**：3秒抓住人，让读者觉得「这就是我」。

**句式**：
`在生活里，有没有过令你XX的场景？` + `比如A，你明明……却……；比如B，你明明……却……；比如C，你想……但听到……便又……。`

**原文示例**：

> 在生活里，有没有过令你纠结难受的场景？
> 比如兄弟找你借钱，你明明无法满足他的需求，却不好意思开口拒绝；
> 比如闺蜜半夜找你吐槽伴侣还要你给建议，你明明不想掺和却没有办法挂断；
> 比如长辈做了你很厌惧的食物，你想放下筷子，但听到对方说"我花了多少多少时间才做好的"，便又心生不忍。

**三场景选取规则**：

- 关系三角：朋友 / 闺蜜（同性密友）/ 长辈（父母、亲戚），覆盖读者80%的人际网；
- 矛盾同构：都是「想拒绝 + 因情面忍住」，动词用「不好意思 / 没有办法 / 心生不忍」递进；
- 细节颗粒度：每场景必须有一个可视化动作（借钱、半夜电话、放下筷子）和一句对方台词（"我花了多少时间……"）。

**可套用模板**：

```text
在生活里，有没有过令你[双字情绪，如疲惫/内耗/委屈]的场景？
比如[人物A][找你做X]，你明明[真实想法]，却[碍于情面的表现]；
比如[人物B][找你做Y]，你明明[真实想法]却[无奈表现]；
比如[人物C][找你做Z]，你想[拒绝动作]，但听到对方说"[一句让你心软的话]"，便又[妥协表现]。
```

## ② 痛点升华 + 抛概念（~150字）

**功能**：把三个场景收成一个「病症」，再给出「药名」。

**句式链**：
`这些场景中累积的[抽象词]，会不断[动词]在你[身体部位]，变成浓郁的[负面词]；消耗着你，周而复始。` → `那么，我们要如何才能打破这种境况，保护自身的[珍贵词]呢？` → `对于这一点，十点君给您一个建议，秘诀就X个字——[核心概念]。`

**原文示例**：

> 这些场景中累积的能量，会不断堆砌在你胸中，变成浓郁的负面情绪；消耗着你，周而复始。
> 那么，我们要如何才能打破这种境况，保护自身的能量呢？
> 对于这一点，十点君给您一个建议，秘诀就5个字——选择性入局。

**要点**：

- 身体隐喻三件套任选：能量/情绪 + 胸中/心里/肩上 + 堆砌/消耗/吞噬；
- 概念字数必须点出来（"秘诀就5个字"），制造记忆点；
- 概念用 `——` 引出，单独成视觉焦点。

## ③ 概念辨析（~250字）

**功能**：给概念下定义，并用"流行语肯定+转折"显得既懂网感又深刻。

**五步**：

1. 设问：`那到底什么是X呢？`
2. 定义：`X，其实就是……，即……。`（后半句用更玄的词拔高，如"境况遭遇，即因果"）
3. 引用流行语：`当下，我们总在社交媒体上看到一句话，叫"……"。`
4. 转折：`但其实，我们就生活在一个……的世界里：` + 3个排比短句（妈妈……必定……；老婆……必定……；长辈……必定……。）
5. 判断：`所以，完全……是很难实现的，也就是说——在生活里，你不可能……。`

**原文示例**：

> 局，其实就是他人的境况遭遇，即他人的因果。
> ……
> 妈妈清晨醒来，听到孩子啼哭，必定要过去安抚哄慰；
> 老婆心情不好，烦闷痛苦，老公必定得去陪伴开解；
> 长辈身体出状况，卧病在床，你总是会去照顾关心的。
> 所以，完全不介入他人因果是很难实现的，也就是说——在生活里，你不可能完全不入局。

**要点**：排比句一律 `人物+触发条件，必定+温情动作`，动词用"安抚/陪伴/照顾"等暖词，与后文"代价"形成张力。

## ④ 个人故事 + 小金句（~500字）

**功能**：用"我"的亲历建立信任，证明"小事也有代价"。

**叙事弧**：日常（每天上午都会……）→ 他人劝（有同事告诉我……我总是笑笑不说话）→ 信念（因为在我心中认为：……不碍事儿）→ 转折（直到有一天……）→ 空缺焦虑（那日因为她没出现，我变得心神不宁。之后一周、两周……）→ 求证（忍耐不住终于问了……）→ 离场+余波（第二学期，我便离开了……牵挂至今）→ 反转感悟（现在回想起来，当初觉得"……"的想法是不对的。）

**原文金句收束**：

> 当她第一天出现，而我接纳了她的时候，我们便已然绑定在了一起。
> ……
> **但凡入局，必定会付出一些什么。**
> 可能是可见的金钱物质，也可能是无形的情感羁绊。
> 总之，**没有一个局是不需要"筹码"的。**

**要点**：

- 身份选"代课老师/新人/租客"等低权力视角，读者易代入；
- 时间词必须具体（每天/有一天/一周两周/第二学期），营造真实感；
- 他人劝告是必需品——"我"不听劝，后文才有后悔的合理性；
- 结尾用"可见的……也可能是无形的……"二分法，把代价从钱拔高到情。

## ⑤ 名人/社会故事 + 类比（~500字）

**功能**：把代价从"情感牵挂"升级到"钱财+关系双输"。

**三件套**：

1. 类比先行：`都知道多米诺骨牌效应。入局就像你碰倒了第一片骨牌，后面的连续倾塌就不是可以轻易控制的。最典型的便是XX。`
2. 名人叙事（以宝石老舅借钱为例）：没钱+不忍（自己也没多少钱……心里不忍）→ 关键牺牲细节（把结婚收的份子钱借了）→ 连带效应123（变紧巴/计划搁置/背负重担）→ 想讨不敢（笃定兄弟很难，只能忍住）→ 鼓勇讨要（终于鼓起勇气……）→ 失联暴击（拨了很多次，电话始终无法接通。那一刻他差点儿"跪在成都的马路上"）→ 网友反应（网友听完……感慨"实在很惨"）。
3. 金句收束：`一旦入了局，后面的一连串多米诺效应，便不是我们能控制的，并非我们想抽身就能抽身。如果强行抽身，那也必定伤筋动骨。` + `每一次入局，都是一次不能轻易下桌的豪赌。`

**要点**：

- 名人选"草根逆袭型"（宝石老舅、大衣哥、张桂梅），自带共情；
- 必须有一个"钱数/物品"细节（份子钱）和一个"身体崩溃"瞬间（跪在马路上）；
- 类比词在段内重复3次（骨牌→倾塌→抽身→下桌），形成隐喻闭环。

## ⑥ 文学影视递进 + 分级（~300字）

**功能**：把代价推到极致——"交出一生"，完成"轻→重"三级跳。

**句式**：`前阵子……作家XX写过……叫《XX》。里面的男主……把……当作……。他见不得……见不得……。故而当……时，他站了出来。` → 简述情节（3-4句，含一个专业手法：伪装/时间诡计/顶罪）→ `很多人……感动于……，可却忽略了他所付出的代价。` → `为了"……"，他从……沦落成……，……，并且……。等于人生尽毁。`

**原文分级金句**（全篇最高点，必须模仿）：

> 在生活里，只要你有助人的动机，无论轻重，代价是肯定的；
> **轻的，花费时间、提供情绪价值；**
> **中的，出钱出力，烧耗自己的资源；**
> **重的，便可能要交出自己的一生。**

**要点**：选案标准——读者大概率听过（《嫌疑人X的献身》《活着》《漫长的季节》），且主角动机是"为爱/为义入局"；情节复述不超过150字，重点永远落在"代价清单"。

## ⑦ 转折 + 三条建议（~600字）

**功能**：防止读者滑向"冷漠"，给出"又暖又边界感"的出路。

**转折模板**（背诵级）：

```text
但讲到这，是不是就意味着，我们完全要[极端做法]，然后[极端做法]，看着别人崩坏也坚决不入局。
十点君绝不是这个意思，而是想说，我们在[动词]时，可以做到有选择地[动词]——
明确哪些人能帮，哪些人不能帮；
哪些事儿能做，哪些事儿不能做；
并且帮到什么程度、做到什么程度？
这些都是我们应当思考和判断的。
在这，十点君给您三个建议，希望对您有所帮助。
```

**每条建议的固定格式**：

```text
N）[8字内对仗小标题，如：划定心理边界，学会"课题分离"]
[1句痛点归因：很多时候，我们之所以……，是因为我们把……当成了……。]
[权威背书：心理学家XX提出…… / XX教授在《XX》一书中，将……分为……。]
[回扣开头的3排比：闺蜜……，如何……，是她的课题；兄弟……，是他的课题；长辈……，是他们的课题。]
[怎么做：我们可以……，但绝不能……。/ 在决定……之前，先……。]
[金句收：不XX，不XX，是你保护自己XX的最好盔甲。/ ……的人，反而最容易……。]
```

**原文两条实证**：

1. 划定心理边界，学会"课题分离" → 阿德勒 → 三排比回扣（闺蜜婚姻/兄弟财务/长辈剩菜）→ "不背负他人的因果，不越界干涉他人的命运，是你保护自己能量的最好盔甲。"
2. 评估自身能量，建立"付出预算" → 亚当·格兰特《给予者》"无私型给予者 vs 自我保护型给予者" → 结论"自我保护型反而最容易成功和幸福"。

**第三条建议补全方向**（原文缺失，写作时必须补足）：建议写「设置退出机制，允许适时离场」，绑定概念可用"沉没成本/及时止损/拒绝话术"，并给一句可直接套用的拒绝话术，如："这件事我这周只能帮到这一步，剩下的需要你自己来了。"

## 过渡句库（段间连接，直接取用）

- ③→④：`而一旦入了局，便多少需要付出一些代价去成全他人。这个代价有可能一开始你根本意识不到。`
- ④→⑤：`并且，一旦我们入了他人的局，便很难轻易脱身。都知道多米诺骨牌效应。`
- ⑤→⑥：`而当我们与他人牵扯越深，我们付出的代价也会越大。`
- ⑥→⑦：`但讲到这，是不是就意味着……？十点君绝不是这个意思，而是想说……`
- 段内万能转折：`但其实 / 所以 / 也就是说 / 直到有一天 / 这下 / 总之 / 并且 / 而 / 现在回想起来`
